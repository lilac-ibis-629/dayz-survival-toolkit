# DayZ Survival Toolkit — feature reference

DayZ Survival Toolkit groups session settings, inventory notes, and map references in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Session settings | Session and activity information grouped by the task or context it belongs to. |
| Inventory notes | Inventory and resource categories organized alongside their related values and notes. |
| Map references | A dedicated section for map references and the configuration details associated with that area. |

The project page follows the same section structure.
